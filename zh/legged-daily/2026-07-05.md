- 2026-07-02 有 3 篇新的 arXiv 条目对本追踪很有价值：重载全尺寸人形遥操作、面向 zero-shot sim-to-real 的执行器接口整形、以及四足机器人借墙支撑的双足步态控制。

### HEFT: Heavy-Payload Full-size Humanoid Teleoperation with Privileged Motion Guidance and Windowed Payload Curriculum
- 链接: https://arxiv.org/abs/2607.02332
- 来源: arXiv
- 日期: 2026-07-02
- 作者: Chenxin Liu, Qingzhou Lu, Guangxiao Yang, Xuanyang Shi, Chenghan Yang, Yanjiang Guo, Jianyu Chen
- 主题: humanoid teleoperation, heavy payload, motion tracking, VR teleoperation, curriculum learning, full-size humanoid
- 摘要: 提出 HEFT，一个面向全尺寸人形机器人的重载遥操作框架，通过 Privileged Motion Guidance 和 Windowed Payload Curriculum，让机器人在嘈杂 VR 参考下进行运动跟踪和负载动作；论文报告在 175 cm、65 kg 的 L7 人形平台上部署，最高负载 24 kg。
- 备注: arXiv 页面列出的项目页为 https://heft.axell.top/ 。这是主论文列表的强候选，因为它关注的是可负载的全尺寸人形遥操作，而不是只在小型人形或无负载 motion tracking 上验证。

### Actuator Reality Shaping for Zero-Shot Sim-to-Real Robot Learning
- 链接: https://arxiv.org/abs/2607.02205
- 来源: arXiv
- 日期: 2026-07-02
- 作者: Satoshi Yamamori, Koji Ishihara, Kentaro Minamikawa, Kiyoharu Ohmori, Taiyo Yazaki, Norikazu Sugimoto, Jun Morimoto
- 主题: sim-to-real, actuator dynamics, robot learning, zero-shot transfer, wheeled-legged robots, humanoid walking
- 摘要: 提出把真实执行器的闭环行为整形成仿真中理想二阶执行器模型的方法，用两自由度前馈-反馈控制器把参考响应整形与鲁棒稳定分离，使策略无需任务级微调或学习式执行器模型即可 zero-shot 部署。
- 备注: 这篇更偏通用 robot learning，但与腿足方向相关，因为摘要明确报告了 wheeled-legged robot 上坡和 humanoid walking 的 zero-shot 演示。

### Multi-Rate Nonlinear Model Predictive Control for Wall-Supported Bipedal Locomotion of Quadrupedal Robots
- 链接: https://arxiv.org/abs/2607.01574
- 来源: arXiv
- 日期: 2026-07-02
- 作者: Taizoon Chunawala, Jeeseop Kim, Kaveh Akbari Hamed
- 主题: quadruped locomotion, bipedal locomotion, wall-supported locomotion, nonlinear MPC, whole-body control, Unitree A1
- 摘要: 提出一个分层 MR-NMPC + nonlinear whole-body control 框架，让四足机器人在狭窄环境中通过墙面支撑执行双足步态；高层在 multi-rate optimal-control 形式下同时规划接触点和 CoM / 姿态连续轨迹。
- 备注: arXiv comments 显示已被 IEEE/RSJ IROS 2026 接收；仿真使用 Unitree A1，并报告相比 heuristic foot placement 的 conventional MPC 成功率提升 2.9 倍。

### darshmenon/quadruped-locomotion-stack
- 链接: https://github.com/darshmenon/quadruped-locomotion-stack
- 类别: quadruped locomotion / RL / ROS 2 / simulation stack
- 机器人类型: 四足；README 列出 Unitree Go2、Spot、Mini Cheetah、ANYmal B/C、Mini Pupper 支持
- 仿真器: MuJoCo / Gazebo Harmonic
- 部署: sim / ROS 2 integration / policy deployment workspace
- 摘要: 偏 Unitree Go2 的四足 locomotion 工作区，组合 ROS 2 CHAMP、Quad-SDK / NMPC 风格控制组件、MuJoCo 与 Gazebo 仿真、PPO 训练脚本、遥操作、导航 / SLAM hooks，以及多机器人 URDF 资产。
- 备注: 更适合作为集成 / 教学型 workspace，而不是已验证的实验室标准 benchmark；价值在于可以快速对照 Go2 类平台上的 classical、NMPC 和 RL locomotion 路径。

### Ayrcs/impakt-robot-soccer-simple-g1-controller
- 链接: https://github.com/Ayrcs/impakt-robot-soccer-simple-g1-controller
- 类别: humanoid robot soccer / ROS 2 / high-level controller / perception-action prototype
- 机器人类型: 人形；Unitree G1
- 仿真器: 未验证
- 部署: hardware / ROS 2 Foxy / Unitree SDK2-style interfaces
- 摘要: 早期实验型 Unitree G1 机器人足球控制器，包含相机图像接收、YOLO 足球检测、头部舵机控制、高层 locomotion command 发布、音频播放，以及 search / follow / stop 等简单行为逻辑。
- 备注: README 强调仍处于研究开发阶段，需要受控环境和人工监督；更适合作为 G1 高层行为 plumbing 的轻量示例，而不是 locomotion policy training 仓库。
