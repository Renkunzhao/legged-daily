# 腿足机器人日报 - 2026-06-30

### VLK: Learning Humanoid Loco-Manipulation from Synthetic Interactions in Reconstructed Scenes
- 链接: https://arxiv.org/abs/2606.30645
- 来源: arXiv
- 日期: 2026-06-29
- 作者: Yen-Jen Wang, Jiaman Li, Sirui Chen, Takara E. Truong, Pei Xu, Pieter Abbeel, Rocky Duan, Koushil Sreenath, Angjoo Kanazawa, Carmelo Sferrazza, Guanya Shi, C. Karen Liu
- 主题: 人形机器人、loco-manipulation、vision-language-kinematics、3D Gaussian Splatting、sim-to-real、Unitree G1
- 摘要: 在 3DGS 重建室内场景中生成 48,000 条配对轨迹，训练 vision-language-kinematics 策略预测短时域全身运动学轨迹，并通过全身跟踪器部署到真实 Unitree G1，完成导航和搬运任务。
- 备注: 项目页：https://vision-language-kinematics.github.io/。这是 Amazon FAR、UC Berkeley、Stanford、CMU 之间的强协作网络信号。

### X-Morph: Human Motion Priors for Scalable Robot Learning Across Morphologies
- 链接: https://arxiv.org/abs/2606.30290
- 来源: arXiv
- 日期: 2026-06-29
- 作者: Shivam Sood, Arhaan Jain, Shyam Charan Kesavamoorthi, Chenyang He, Guillaume Adrien Sartoretti
- 主题: 四足、六足、带机械臂四足、重定向、强化学习、行为先验、遥操作
- 摘要: 通过跨形态重定向、privileged RL 跟踪和 causal student policy 蒸馏，把人类运动转换为非人形腿足机器人的可部署运动与 loco-manipulation 策略。
- 备注: 项目页：https://maker-rat.github.io/morph/。本次未验证到官方代码发布。

### KYON: Semi-Modular Wheel-Legged Quadruped With Agile Bimanual Capability
- 链接: https://arxiv.org/abs/2606.30243
- 来源: arXiv
- 日期: 2026-06-29
- 作者: Luca Rossini et al.
- 主题: 轮腿四足、双臂操作、全身控制、强化学习、硬件设计
- 摘要: 提出 KYON：带双臂上身的混合轮腿四足机器人；其半模块化下肢设计支持轮式和腿式运动，并通过基座内置驱动和传动机构降低远端惯量。
- 备注: 适合作为 loco-manipulation 硬件平台信号；正式进入主列表前建议从 PDF 复核完整作者列表。

### LeggedGym-Ex
- 链接: https://github.com/lupinjia/LeggedGym-Ex
- 类别: RL / 仿真器 / 工具包
- 机器人类型: 四足 / 人形 / 双足
- 仿真器: IsaacGym / Genesis / IsaacSim
- 部署: 仿真与实机
- 摘要: 基于 legged_gym 的腿足机器人训练框架，支持 IsaacGym、Genesis、IsaacSim，并包含 Unitree Go2、Unitree G1 DeepMimic、Booster K1、TRON1、DreamWaQ、AMP、teacher-student learning、深度图跑酷等示例。
- 备注: README 记录了 2026 年近期更新，包括云端训练 Dockerfile / viser 可视化、warp-based height query 和最新 rsl-rl-lib 支持。
