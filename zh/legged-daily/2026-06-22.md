# 腿足机器人日报 - 2026-06-22

## 摘要
- 周一 arXiv 还没有出现比 6 月 17-18 日这批已核验投稿更新的腿足机器人论文流，所以今天优先补充最近草稿中尚未重点展开的高信号条目。
- 主动脚趾双足硬件是今天最强论文信号：一项 14-DoF 双足研究系统量化 active toes 对敏捷性、效率和吸收冲击的影响，并使用包含真实执行器与功耗建模的高保真仿真环境。
- 非惯性地面上的本体感知状态估计是很有用的人形鲁棒性信号，尤其适合没有外部地面运动测量的移动平台场景。
- ZiMPedance 从负载稳定性角度补充四足运输问题，把被动弹簧阻尼负载接口纳入 ZMP 分析，并用硬件实验验证控制设计。
- 仓库观察：StepIt 是一个小而活跃的腿足机器人 / 输入设备 / 学习控制器连接框架；一个 Unitree G1 MuJoCo MPC/WBC 环境也值得作为经典控制参考预览。
- 机会观察仍然有效：EPFL BioRob 有 Fall 2026 人形 neuromechanics PhD/Postdoc；ETH RSL 持续列出腿足机器人方向 PhD/Postdoc/research staff/工程岗位。

### Comparative Study on Agility, Efficiency, and Impact Absorption of Bipedal Robots with Active Toes
- Link: https://arxiv.org/abs/2606.19699
- Source: arXiv
- Date: 2026-06-18
- Authors: Joong-Gil Kim, Wontae Ye, Geunwoo Cho, Seong-Ho Yun, Se-Hyoung Cho, Yong-Jae Kim
- Topics: biped / active toes / hardware design / locomotion / agility / efficiency / impact absorption
- Summary: 提出一个带轻量高扭矩主动脚趾的 14-DoF 双足机器人，并在高保真仿真环境中比较不同脚趾配置；环境显式考虑真实执行器、耦合传动和功耗，用于更公平地评估主动脚趾对敏捷性、效率和冲击吸收的影响。
- Notes: 适合作为足部 / 脚趾 morphology 如何影响运动性能的跟踪对象，而不只是把脚当成被动接触几何。

### Proprioceptive Invariant State Estimation for Humanoid Robots on Non-Inertial Ground
- Link: https://arxiv.org/abs/2606.19512
- Source: arXiv
- Date: 2026-06-17
- Authors: Falak Mandali, Zijian He, Yan Gu
- Topics: humanoid / state estimation / invariant EKF / proprioception / moving ground / non-inertial environments
- Summary: 提出面向移动或非惯性地面的人形机器人本体感知 InEKF，在没有直接测量地面运动、也不依赖外部传感器的情况下，利用机载传感和支撑脚运动学约束估计相对移动地面的 base position 与 velocity。
- Notes: 对船舶、电梯、车辆等移动支撑面上的人形部署很相关，因为固定世界假设和外部 tracking 往往不成立。

### ZiMPedance: Impedance-Aware ZMP Modeling and Control for Payload Carrying with Quadruped Robots
- Link: https://arxiv.org/abs/2606.18883
- Source: arXiv
- Date: 2026-06-17
- Authors: Giovanni B. Dessy, Lorenzo Amatucci, Victor Barasuol, Claudio Semini
- Topics: quadruped / payload carrying / impedance / ZMP / MPC / passive arms / stability
- Summary: 面向四足机器人负载运输，把被动弹簧阻尼负载接口的动力学加入 Zero Moment Point 建模，分析 stiffness、damping 和 load mass 对稳定裕度的影响，并据此改进控制器设计。
- Notes: 对使用轻量被动接口而不是全主动机械臂来搬运负载的四足应用很有参考价值。

### chengruiz/stepit
- Link: https://github.com/chengruiz/stepit
- Category: toolkit / control / RL / input interface
- Robot Type: legged / general
- Simulator: none
- Deploy: hardware
- Summary: 活跃的 C++ 框架，用于连接腿足机器人、输入设备和控制算法，尤其面向 learning-based policies；包含 control console、joystick interfaces、robot interfaces、state machines、replay utilities 等插件式组件。
- Notes: README 明确说明项目仍在 active development、接口可能不稳定；相关策略和配置通过 `stepit_zoo` 引用。

### matteogoddi/labrob_mujoco_environment
- Link: https://github.com/matteogoddi/labrob_mujoco_environment
- Category: MPC / whole-body control / simulator
- Robot Type: humanoid / Unitree G1
- Simulator: MuJoCo
- Deploy: sim
- Summary: 基于 MuJoCo 的 Unitree G1 行走环境，控制链路包含 offline footstep planner、EKF 状态估计、IS-MPC 质心轨迹生成，以及用于参考跟踪和接触 / 运动学约束的 whole-body controller。
- Notes: 仓库规模较小、更像研究 / 教学代码，但适合作为 G1 locomotion 经典控制 baseline 阅读。
