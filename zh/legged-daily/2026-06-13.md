# 腿足机器人日报 - 2026-06-13

## 摘要
- 今天最强的新论文信号仍然来自 humanoid whole-body control：WT-UMI 面向大型、柔性、共同搬运物体，加入 force-supervised tactile planning；Stubborn 则把 humanoid motion tracking 与 fall recovery 放进统一 RL 框架。

- SUSTech ACT Lab 值得继续跟踪 humanoid robust tracking / fall recovery；Xidian XDEI group 值得作为 quadruped embodied-agent deployment 来源跟踪。
- 官方招聘复查显示：EPFL BioRob humanoid neuromechanics PhD/Postdoc 与 ETH RSL 滚动 legged robotics 岗位仍为 active。

### WT-UMI: Tactile-based Whole-Body Manipulation via Force-Supervised Contact-Aware Planning
- Link: https://arxiv.org/abs/2606.13232
- Source: arXiv
- Date: 2026-06-11
- Authors: Jaehwi Jang, Zhaoyuan Gu, Alfred Cueva, Zimeng Chai, Junjie Sheng, Thong Nguyen, Himank Galundia, Yifan Wu, Huishu Xue, Isaac Legene, Ojas Mediratta, Davin Doan, Andrew Collins, Sarah Sadegh, KyoungMok Kim, Rishita Dhalbisoi, Zun Chen, Ye Zhao
- Topics: humanoid / whole-body manipulation / tactile sensing / contact force / imitation learning / admittance control
- Summary: 提出 WT-UMI，一种可由人类示教者穿戴、也可安装在 humanoid 上的 whole-body tactile interface，用于采集 tactile images、contact forces 与 end-effector poses，并通过 force-conditioned pose correction、force-supervised planning 和 tactile admittance control 完成接触丰富的 humanoid manipulation。
- Notes: 项目页： https://wt-umi.github.io/WTUMI/ 。对大型、柔性、共同搬运物体尤其相关，因为这类任务中纯 pose-based imitation 往往不足以处理接触力。

### Stubborn: A Streamlined and Unified Reinforcement Learning Framework for Robust Motion Tracking and Fall Recovery for Humanoids
- Link: https://arxiv.org/abs/2606.12814
- Source: arXiv
- Date: 2026-06-11
- Authors: Xiao Ren, Yuhui Yang, Zongbiao Weng, Zhijie Liu, He Kong
- Topics: humanoid / reinforcement learning / motion tracking / fall recovery / robustness
- Summary: 提出统一的 humanoid motion tracking 与 fall recovery RL 框架，结合 yaw-aligned tracking representation、asymmetric actor-critic、Bernoulli-based probabilistic termination 和 adaptive sampling，避免为恢复行为单独训练 policy 或复杂多阶段训练。
- Notes: 项目页： https://aislab-sustech.github.io/Stubborn/ 。页面展示了与 SOTA tracking methods 的比较和真实机器人演示；本轮未验证到代码开源。

### Y-BotFrame: An Extensible Embodied Agent Framework for Quadruped Robot Assistants
- Link: https://arxiv.org/abs/2606.13049
- Source: arXiv
- Date: 2026-06-11
- Authors: Luyao Zhang, Ke Li, Yuan Ding, Xulong Zhao, Guo Yu, Chengwei Yan, Fuyu Dong, Jiawei Hu, Di Wang, Nan Luo, Gang Liu, Quan Wang
- Topics: quadruped / embodied agents / multimodal perception / LLM planning / navigation / human-robot interaction
- Summary: 提出 Y-BotFrame，一个 quadruped embodied-agent framework，融合 speech、vision、LiDAR、LLM reasoning、task planning、可执行模块和机器人侧反馈，把四足机器人变成 instruction-driven ground assistant。
- Notes: 项目页： https://xdei-group.github.io/Y-BotFrame/ 。它更偏 embodied-agent 系统集成而不是 locomotion control，但作为 quadruped deployment / interaction stack 有跟踪价值。

### mpc-rl
- Link: https://github.com/junhengl/mpc-rl
- Category: RL / MPC / simulator / toolkit
- Robot Type: humanoid
- Simulator: MuJoCo / mujoco-warp
- Deploy: sim / hardware-related training validation
- Summary: “Accelerating and Scaling MPC-Guided Reinforcement Learning for Humanoid Locomotion and Manipulation”的官方代码，包含 humanoid locomotion 与 loco-manipulation 训练环境，以及用于训练期 RL guidance 的 batched GPU centroidal MPC solver。
- Notes: 2026-06-13 GitHub API 检查显示仓库创建于 2026-06-03，更新于 2026-06-13。README 说明仓库包含 training environments、MPC 与 JAX/PyTorch batched solver，并支持 locomotion 与 box-pushing loco-manipulation 任务。

### unitree_lerobot
- Link: https://github.com/unitreerobotics/unitree_lerobot
- Category: imitation learning / dataset / toolkit / deployment
- Robot Type: humanoid / manipulator
- Simulator: Isaac Lab via linked Unitree simulation environment

- Summary: Unitree 维护的 LeRobot adaptation，用于 Unitree G1、Z1、Dex1、Dex3 硬件上的训练、数据转换、dataset replay、model deployment 与 real-machine validation。
