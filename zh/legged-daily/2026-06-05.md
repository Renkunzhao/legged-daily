# Legged Daily - 2026-06-05

## 摘要
- 今天最强的新论文信号是 Caltech / Johns Hopkins 的 MPC-RL：用训练期的质心动力学 MPC 引导和批量 GPU MPC 求解器，扩展人形机器人的移动与操作强化学习。
- MotionDisco 给出另一条人形 loco-manipulation 路线：LLM 引导的进化搜索加运动学/动力学轨迹优化，不依赖遥操作或人体动作重定向，从零发现长时域接触丰富技能。
- M3imic / MultiModalWBC 同时是论文和实现信号：在 Isaac Lab 中统一关节轨迹、人体姿态轨迹和末端执行器参考，用于 Unitree G1 全身控制。
- 仓库信号有用但成熟度不同：MultiModalWBC 看起来已经提供训练与数据入口；mpc-rl 是论文官方仓库，但 README 说明代码仍在准备中。
- 招聘检查确认 EPFL BioRob、ETH RSL，以及 Stanford / Karen Liu 相关的可穿戴步态 postdoc 仍活跃；今天没有提出已验证的过期删除项。

### Accelerating and Scaling MPC-Guided Reinforcement Learning for Humanoid Locomotion and Manipulation
- Link: https://arxiv.org/abs/2606.05687
- Source: arXiv
- Date: 2026-06-04
- Authors: Junheng Li, Liang Wu, Sergio A. Esteban, Lizhi Yang, Ján Drgoňa, Aaron D. Ames
- Topics: humanoid / locomotion / loco-manipulation / MPC / reinforcement learning / batched GPU optimization
- Summary: 研究用于人形机器人移动与操作 RL 的训练期 MPC 引导，提出质心动力学 MPC 奖励和 $\pi^n$MPC——一种 construction-free 的批量 GPU MPC 求解器，用于在大规模并行 RL 中扩展 MPC 指导；摘要报告了对比实验和硬件验证，并显示移动与操作性能提升。
- Notes: 官方代码链接：https://github.com/junhengl/mpc-rl。arXiv HTML 中的机构为 California Institute of Technology 和 Johns Hopkins University；仓库 README 当前说明代码仍在准备中。

### MotionDisco: Motion Discovery for Extreme Humanoid Loco-Manipulation
- Link: https://arxiv.org/abs/2606.06139
- Source: arXiv
- Date: 2026-06-04
- Authors: Ilyass Taouil, Michal Ciebielski, Shafeef Omar, Haizhou Zhao, Angela Dai, Aaron M. Johnson, Majid Khadiv
- Topics: humanoid / loco-manipulation / motion discovery / LLM-guided search / kinodynamic optimization / reinforcement learning
- Summary: 提出 MotionDisco，通过 LLM 引导的交互序列进化搜索、顺序 kinodynamic 轨迹优化和剪枝，从零发现接触丰富、长时域的人形 loco-manipulation 动作；随后训练 RL 跟踪策略，将发现的动作迁移到真实人形机器人。
- Notes: 补充视频：https://youtu.be/DHiVz34QYlw。arXiv HTML 列出的机构包括 Technical University of Munich、New York University 和 Carnegie Mellon University。今天未验证到公开代码仓库。

### M3imic: Learning a Versatile Whole-Body Controller for Multimodal Motion Mimicking
- Link: https://arxiv.org/abs/2606.04829
- Source: arXiv / IEEE Robotics and Automation Letters
- Date: 2026-06-03
- Authors: Zuxing Lu, Ziang Zheng, Yao Lyu, Jingyu Liu, Feihong Zhang, Song Lu, Xin Yuan, Changyin Sun, Xingxing Zuo, Shengbo Eben Li
- Topics: humanoid / whole-body control / motion imitation / multimodal references / sim-to-real / Unitree G1
- Summary: 提出 Multi-Modal Mimic（M3imic）全身控制框架，将机器人关节角、人体姿态轨迹和末端执行器姿态等异构运动参考映射到共享 latent space，使单一策略可支持移动与 loco-manipulation 参考；摘要报告了 Unitree G1 sim-to-real 实验，以及未见测试集 98.42% 的仿真峰值成功率。
- Notes: 官方代码：https://github.com/Renforce-Dynamics/MultiModalWBC。arXiv HTML 显示论文于 2026-06-01 接收；机构包括 Southeast University、Tsinghua University 和 MBZUAI。
