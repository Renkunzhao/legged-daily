# Legged Daily - 2026-06-01

## Summary
- New arXiv signal is strongest around legged loco-manipulation, GPU-native dynamics for robot learning, and humanoid human-in-the-loop manipulation.
- TA-WBC is a high-fit legged-manipulator paper because it explicitly combines terrain exteroception, whole-body control, RL, and real-world experiments.
- BARD is worth tracking both as a paper and repository: it targets batched differentiable rigid-body dynamics inside GPU robot-learning pipelines and reports quadruped integration in Isaac Lab AMP.
- Hugging Face / Pollen released LeRobot Humanoid as a low-cost open bipedal platform with hardware, runtime, identification, and MJLab training components; the main repos are still experimental but high-signal for open humanoid learning.
- EPFL BioRob's humanoid neuromechanics PhD/Postdoc opening remains active and official; no stale job removal was identified today.

<summary><strong>New Papers</strong></summary>

### Learning Terrain-Aware Whole-Body Control for Perceptive Legged Loco-Manipulation
- Link: https://arxiv.org/abs/2605.31343
- Source: arXiv
- Date: 2026-05-29
- Authors: Sikai Guo, Yudong Zhong, Guoyang Zhao, Botao Dang, Zhihai Bi, Jun Ma
- Topics: legged manipulators / whole-body control / loco-manipulation / terrain perception / reinforcement learning / sim-to-real
- Summary: Introduces TA-WBC, an RL-based terrain-aware whole-body control framework for legged manipulators that uses hybrid exteroception, foot-contact-plane-based end-effector sampling, and dual-policy distillation to improve cross-terrain loco-manipulation in simulation and real-world experiments.
- Notes: Strong daily candidate because it directly links terrain perception, foothold/posture adaptation, and legged mobile manipulation.

### Batched Differentiable Rigid Body Dynamics in PyTorch for GPU-Accelerated Robot Learning
- Link: https://arxiv.org/abs/2605.31481
- Source: arXiv
- Date: 2026-05-29
- Authors: Yue Wang, Yanran Xu, Wenbo Wu, Chuanhang Qiu, Zhaoxing Li
- Topics: robot dynamics / differentiable simulation / PyTorch / GPU acceleration / reinforcement learning / quadruped
- Summary: Presents BARD, a PyTorch-native batched articulated rigid-body dynamics library that supports GPU acceleration and autograd, matching Pinocchio numerically while reporting large throughput gains for FK/Jacobians and integration into Isaac Lab AMP training for an 11-DOF spined quadruped.
- Notes: Repository: https://github.com/YueWang996/bard-pytorch-dynamics.

### Gaze2Act: Gaze-Conditioned Vision-Language-Action Policies for Interactive Robot Manipulation
- Link: https://arxiv.org/abs/2605.30282
- Source: arXiv
- Date: 2026-05-28
- Authors: Kuangji Zuo, Gen Li, Bofan Lyu, Yanshuo Lu, Boyu Ma, Shijia Han, Xinyu Zhou, Xichen Yuan, Chuhao Zhou, Jiaqi Bai, Geng Li, Jianfei Yang
- Topics: humanoid / VLA / human-robot interaction / gaze conditioning / manipulation / Unitree G1
- Summary: Proposes using human gaze as a continuous intent signal for VLA manipulation, projecting first-person gaze into the robot view and evaluating across 16 real-robot tasks on a Unitree G1 humanoid.
- Notes: Adjacent to locomotion but high-signal for humanoid interaction stacks; project/GitHub page: https://github.com/zuo-kuangji/Gaze2Act.

### BARD PyTorch Dynamics
- Link: https://github.com/YueWang996/bard-pytorch-dynamics
- Category: dynamics / toolkit
- Robot Type: general / quadruped
- Simulator: Isaac Lab integration reported in paper
- Deploy: sim
- Summary: PyTorch-native rigid-body dynamics library for URDF-loaded robots with batched CPU/GPU computation, autograd, floating-base support, FK, Jacobians, RNEA, ABA, and CRBA.
- Notes: GitHub README reports PyTorch-native ML workflow integration and benchmark comparisons against Pinocchio; arXiv paper reports use inside an 11-DOF spined quadruped AMP pipeline.

### LeRobot Humanoid
- Link: https://github.com/Virgileboat/lerobot-humanoid
- Category: hardware / simulator / toolkit
- Robot Type: humanoid / biped
- Simulator: MJLab via related training zoo
- Deploy: both
- Summary: Main open workspace for Hugging Face / Pollen's low-cost experimental bipedal humanoid platform, intended to connect hardware design, simulation, data collection, identification, training, and real-world control.
- Notes: Official Hugging Face blog describes a roughly USD 2,500 parts-cost bipedal platform with hardware files, assembly documentation, runtime tools, identification pipelines, and training environments; repository owner is currently Virgileboat rather than the Hugging Face organization.

### LeRobot Legged Zoo
- Link: https://github.com/Virgileboat/lerobot-legged-zoo
- Category: simulator / RL / training environments
- Robot Type: humanoid / legged
- Simulator: MJLab
- Deploy: sim
- Summary: MJLab training examples and legged robot models for LeRobot/Pollen platforms, including LeRobot Humanoid; the repository description notes that it does not provide pretrained policies.
- Notes: Useful as the training-environment side of the LeRobot Humanoid release; currently early-stage and should be treated as experimental.
