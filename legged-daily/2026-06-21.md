### SWAP: Symmetric Equivariant World-Model for Agile Robot Parkour
- Link: https://arxiv.org/abs/2606.19928
- Source: arXiv
- Date: 2026-06-18
- Authors: Kaixin Lan, Ze Wang, Hongyi Li, Lei Jiang, Chaojie Fu, Chengkai Su, Choi Lam Wong, Yongbin Jin, Hongtao Wang
- Topics: quadruped / parkour / world models / symmetry equivariance / reinforcement learning
- Summary: Introduces an end-to-end symmetric equivariant world model and actor-critic policy for quadruped parkour, embedding left-right symmetry as a structural prior for latent dynamics and control; reports real-world 2.13 m gap leaping and 1.63 m platform climbing on an Apollo quadruped, plus zero-shot outdoor transfer.
- Notes: Project page: https://swap-parkour.github.io. Good candidate for tracking world-model-based locomotion and structural-prior approaches.

### CTS-MoE: Implicit Terrain Adaptation via Mixture-of-Experts for Perceptive Locomotion
- Link: https://arxiv.org/abs/2606.19633
- Source: arXiv
- Date: 2026-06-17
- Authors: Francisco Affonso, Matheus P. Angarola, Ana Luiza Mineiro, Aditya Potnis, Marcelo Becker, Girish Chowdhary
- Topics: legged locomotion / quadruped / perception / mixture-of-experts / reinforcement learning / terrain adaptation
- Summary: Proposes a dense mixture-of-experts actor with perception-conditioned routing and task-specific value heads for Unitree Go1 locomotion across stairs, gaps, slopes, and terrain transitions; routing uses perception at deployment rather than explicit task labels.
- Notes: Project page: https://cts-moe.github.io/. Relevant to terrain-adaptive policy architectures and concurrent teacher-student RL.

### HALOMI: Learning Humanoid Loco-Manipulation with Active Perception from Human Demonstrations
- Link: https://arxiv.org/abs/2606.18772
- Source: arXiv
- Date: 2026-06-17
- Authors: Zehui Zhao, Yuxuan Zhao, Gaojing Zhang, Chenxi Liu, Maolin Zheng, Wenzhao Lian
- Topics: humanoid / loco-manipulation / imitation learning / active perception / whole-body control / Unitree G1
- Summary: Presents a scalable pipeline for transferring egocentric human demonstrations to humanoid loco-manipulation, combining UMI-style hand data, head-mounted egocentric sensing, view alignment, controller-aware reference adaptation, and a manifold-constrained whole-body controller; reports 85% average success across three evaluated real-world tasks on Unitree G1.
- Notes: Project page: https://halomi-humanoid.github.io. Useful for tracking human-data-to-humanoid transfer.

### ARCaD-Lab-UM/surge-codesign
- Link: https://github.com/ARCaD-Lab-UM/surge-codesign
- Category: control / RL / co-design / toolkit
- Robot Type: legged / hopper
- Simulator: Isaac Gym
- Deploy: both
- Summary: Official implementation of “SurGE: Surrogate Gradient-guided Evolution for Co-design of Legged Robots with Parallel Elasticity,” jointly optimizing spring design and control policy with a surrogate-gradient-injected CMA-ES pipeline.
- Notes: Repository says IROS 2026 and paper coming soon; includes pretrained checkpoints and customized legged-gym / rsl_rl packages. Treat venue/paper status as author-stated until official proceedings/arXiv are available.

### ori-drs/pronto
- Link: https://github.com/ori-drs/pronto
- Category: state estimation / toolkit / ROS
- Robot Type: humanoid / quadruped / general legged
- Simulator: none
- Deploy: hardware
- Summary: Modular EKF state estimator for legged robots using proprioceptive and exteroceptive fusion, with modules for biped and quadruped leg odometry; README notes ROS 2 Humble support on the main branch.
- Notes: Historically used on Atlas, Valkyrie, HyQ, and ANYmal; updated recently and worth keeping as a classical state-estimation baseline.

### gpai-robotics/go2-lab-rough-terrain-locomotion
- Link: https://github.com/gpai-robotics/go2-lab-rough-terrain-locomotion
- Category: RL / locomotion / deployment pipeline
- Robot Type: quadruped / Unitree Go2
- Simulator: IsaacLab / MuJoCo
- Deploy: both
- Summary: Public Unitree Go2 rough-terrain locomotion pipeline using blind history-conditioned asymmetric PPO, with actor-only deployment observations, privileged critic training signals, IsaacLab training, MuJoCo/Unitree FSM validation, and hardware deployment notes.
- Notes: Low-star but detailed deployment-oriented release; good candidate to inspect before adding to the formal repo list.
