# Legged Daily - 2026-06-10

## Summary
- Humanoid locomotion updates were especially active on arXiv today, with new work on high-impulse soccer shooting, terrain-aware autonomous navigation, and sparse-foothold perceptive locomotion.
- RoboNaldo is the most hardware-grounded new paper signal: it reports real Unitree G1 soccer shooting with onboard perception and less-than-1-meter average target error from 3 m.
- GuideWalk and MARCH both target the navigation/foothold gap between robust low-level humanoid locomotion and terrain-aware decision making.
- Two useful repository signals surfaced: an IIT DLS IsaacLab quadruped locomotion stack with sim-to-real support, and PHUMA, a physically reliable humanoid locomotion dataset with code and Hugging Face data.
- CUHK Legged Robot Lab is worth tracking as a source: its public page lists Fall 2027 PhD interest plus RA/engineer openings, and reports an RSS 2026 legged-actuation paper.
- Job signals remain active at EPFL BioRob and Field AI for humanoid/legged locomotion, RL, planning, and sim-to-real work.

<summary><strong>New Papers</strong></summary>

### RoboNaldo: Accurate, Stable and Powerful Humanoid Soccer Shooting via Motion-Guided Curriculum Reinforcement Learning
- Link: https://arxiv.org/abs/2606.11092
- Source: arXiv
- Date: 2026-06-09
- Authors: Yichao Zhong, Yidan Lu, Yuhang Lu, Tianyang Tang, Haoguang Mai, Yixuan Pan, Tianyu Li, Li Chen, Jingbo Wang, Zhongyu Li, Peng Lu, Hongyang Li
- Topics: humanoid / locomotion / reinforcement learning / motion tracking / whole-body interaction
- Summary: Introduces a three-stage motion-guided curriculum RL method for humanoid soccer shooting, using a single human-kick reference as a scaffold and progressively adapting to stationary and moving-ball cases; reports real-world Unitree G1 results with 0.73 m and 0.86 m average target error from 3 m and 13.10 m/s post-contact ball velocity.
- Notes: Project page: https://opendrivelab.com/RoboNaldo/ . The project page lists a code link, but the linked GitHub repository returned 404 when checked on 2026-06-10, so code availability is not verified.

### GuideWalk: Learning Unified Autonomous Navigation and Locomotion for Humanoid Robots across Versatile Terrains
- Link: https://arxiv.org/abs/2606.10449
- Source: arXiv
- Date: 2026-06-09
- Authors: Haoxuan Han, Chen Chen, Linao Gong, Xin Yang, Hao Hu, Junhong Guo, Zhicheng He, Yao Su, Fenghua He
- Topics: humanoid / navigation / locomotion / terrain adaptation / robot learning
- Summary: Proposes an end-to-end humanoid navigation and locomotion framework that combines traversability-aware navigation guidance with a terrain-adaptive locomotion teacher, aiming to coordinate obstacle avoidance with dynamically feasible humanoid motion.
- Notes: High relevance for bridging high-level navigation and low-level humanoid locomotion across varied terrains.

### MARCH: Model-Assisted Reinforcement Learning for the Perceptive Control of Humanoids over Sparse Footholds
- Link: https://arxiv.org/abs/2606.10288
- Source: arXiv
- Date: 2026-06-09
- Authors: Codrin Crismariu, Ryan K. Cosner
- Topics: humanoid / bipedal locomotion / perceptive control / sparse footholds / model-assisted RL
- Summary: Combines simplified-model reference generation with reinforcement learning to improve humanoid locomotion over sparse footholds, targeting safety-critical terrain where purely model-free methods struggle to discover precise contact behavior.
- Notes: Useful to track alongside work on foothold tracking, parkour, and hybrid model-based/model-free humanoid control.

### basic-locomotion-isaaclab
- Link: https://github.com/iit-DLSLab/basic-locomotion-isaaclab
- Category: RL / simulator / toolkit
- Robot Type: quadruped
- Simulator: Isaac Lab / MuJoCo
- Deploy: both
- Summary: IIT DLS IsaacLab extension for quadruped locomotion tasks across Aliengo, Go2, B2, and HyQReal2, including sim-to-sim and sim-to-real pipelines.
- Notes: README lists concurrent state estimation, rapid motor adaptation, morphological symmetries, adversarial motion priors, ROS2 deployment, Unitree communication, and robot identification support.

### PHUMA
- Link: https://github.com/DAVIAN-Robotics/PHUMA
- Category: dataset / retargeting / toolkit
- Robot Type: humanoid
- Simulator: Isaac Gym / Isaac Sim
- Deploy: both
- Summary: Code and data pipeline for “PHUMA: Physically Reliable Humanoid Locomotion Dataset,” a 73-hour physically curated and retargeted humanoid locomotion corpus with G1 and H1-2 support.
- Notes: Project page and dataset: https://davian-robotics.github.io/PHUMA/ and https://huggingface.co/datasets/DAVIAN-Robotics/PHUMA . README says PHUMA is natively supported in NVIDIA ProtoMotions.

### WholebodyVLA
- Link: https://github.com/OpenDriveLab/WholebodyVLA
- Category: toolkit / viewer
- Robot Type: humanoid
- Simulator: none
- Deploy: data
- Summary: Resource repository for “Towards Unified Latent VLA for Whole-body Loco-manipulation Control,” collecting project links and a curated list of humanoid VLA / loco-manipulation work.
- Notes: The README explicitly says there is no concrete timeline for open-sourcing the codebase, so this should be treated as a reference/resource repository rather than runnable code.
