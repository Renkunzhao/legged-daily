<summary><strong>New Papers</strong></summary>

### HANDOFF: Humanoid Agentic Task-Space Whole-Body Control via Distilled Complementary Teachers
- Link: https://arxiv.org/abs/2606.06493
- Source: arXiv cs.RO
- Date: 2026-06-04
- Authors: Lizhi Yang, Junheng Li, Nehar Poddar, Yiling Hou, Gio Huh, Robert Griffin, Georgia Gkioxari, Aaron Ames
- Topics: humanoid / whole-body control / loco-manipulation / policy distillation / VLM planning
- Summary: Introduces HANDOFF, a Unitree G1 whole-body controller that exposes a compact task-space command interface and distills three complementary teachers for motion tracking, locomotion, and fall recovery into a mixture-of-experts student, enabling language-driven task rollouts without task-specific controller fine-tuning.
- Notes: High long-term relevance because it connects task planning interfaces, robust humanoid locomotion, manipulation workspace, and agentic VLM planning.

### MotionDisco: Motion Discovery for Extreme Humanoid Loco-Manipulation
- Link: https://arxiv.org/abs/2606.06139
- Source: arXiv cs.RO
- Date: 2026-06-04
- Authors: Ilyass Taouil, Michal Ciebelski, Shafeef Omar, Haizhou Zhao, Angela Dai, Aaron M. Johnson, Majid Khadiv
- Topics: humanoid / loco-manipulation / contact-rich motion discovery / LLM-guided search / trajectory optimization / reinforcement learning
- Summary: Presents an automated framework that uses LLM-guided evolutionary search, sequential kinodynamic trajectory optimization, and RL tracking policies to discover and transfer long-horizon contact-rich humanoid loco-manipulation skills to real hardware.
- Notes: Useful as a planning-and-control counterpart to demonstration-heavy humanoid pipelines because it does not rely on teleoperation or human motion retargeting.

### Accelerating and Scaling MPC-Guided Reinforcement Learning for Humanoid Locomotion and Manipulation
- Link: https://arxiv.org/abs/2606.05687
- Source: arXiv cs.RO
- Date: 2026-06-04
- Authors: Junheng Li, Liang Wu, Sergio A. Esteban, Lizhi Yang, Ján Drgoňa, Aaron D. Ames
- Topics: humanoid / MPC / reinforcement learning / locomotion / manipulation / GPU optimization
- Summary: Studies training-time MPC guidance for humanoid RL and introduces a centroidal-dynamics MPC reward plus a batched GPU MPC solver, πⁿMPC, designed to scale MPC-RL for locomotion and manipulation with hardware validation.
- Notes: The paper links directly to the `mpc-rl` repository; code is announced but not yet available at the time of this check.
