# Legged Daily - 2026-07-02

## Summary
- The highest-signal new arXiv item is a July 1 quadruped locomotion paper that uses Signal Temporal Logic (STL) specifications to shape interpretable gait rewards for PPO.
- Two June 30 humanoid papers are worth tracking: passive inline-skating humanoid control from ETH-related authors, and FastDSAC for scalable off-policy humanoid locomotion.
- FastDSAC now has a public implementation with HumanoidBench and MuJoCo Playground support, making it the strongest repository signal today.
- Repository scan also found an Isaac Lab quadruped fault-locomotion environment with sim-to-real/deployment notes, and a manager-based Isaac Gym locomotion framework.
- Job check: ETH RSL rolling openings remain active; EPFL BioRob PhD signal remains relevant, but the same EPFL page states the related postdoc position is now closed.

<summary><strong>New Papers</strong></summary>

### Learning Gait-Aware Quadruped Locomotion with Temporal Logic Specifications
- Link: https://arxiv.org/abs/2607.00442
- Source: arXiv
- Date: 2026-07-01
- Authors: Merve Atasever, Cagan Bakirci, Alfredo Reina Corona, Keyan Azbijari, Jyotirmoy V. Deshmukh
- Topics: quadruped locomotion, reinforcement learning, Signal Temporal Logic, gait specification, PPO, interpretable rewards
- Summary: Introduces parameterized Signal Temporal Logic constraints for quadruped gait regimes and converts smooth STL robustness into dense PPO-compatible reward shaping for gait-aware locomotion.
- Notes: Useful as a specification-driven RL reference because it explicitly encodes safety, gait synchronization, command tracking, and actuation bounds instead of relying only on hand-crafted Markovian rewards.

### Reinforcement Learning-Based Control for an Inline Skating Humanoid Robot
- Link: https://arxiv.org/abs/2606.31807
- Source: arXiv
- Date: 2026-06-30
- Authors: Ethan Marot, Thomas Bi, Clemens Schwarke, Victor Klemm, Marco Hutter, Raffaello D'Andrea
- Topics: humanoid locomotion, reinforcement learning, passive inline skates, underactuated locomotion, dynamic balance
- Summary: Trains and deploys an RL policy for a humanoid robot modified with passive inline skates, producing edge-driven skating strategies without human motion data, imitation learning, or kinematic priors.
- Notes: arXiv listing notes acceptance at IROS 2026. Strong lab-signal item because it connects dynamic humanoid locomotion with Marco Hutter / Raffaello D'Andrea author networks.

### FastDSAC: Enhancing Policy Plasticity via Constrained Exploration for Scalable Humanoid Locomotion
- Link: https://arxiv.org/abs/2606.31691
- Source: arXiv
- Date: 2026-06-30
- Authors: Guanchen Lu, Yajuan Dun, Yi Zhou, Letian Tao, Jingliang Duan, Jie Li, Guofa Li
- Topics: humanoid locomotion, off-policy reinforcement learning, distributional actor-critic, constrained exploration, MuJoCo Playground, HumanoidBench
- Summary: Proposes FastDSAC, a distributional actor-critic variant that uses truncated Gaussian target actions to constrain exploration and preserve policy plasticity under high-throughput parallel sampling.
- Notes: The public repository reports support for HumanoidBench and MuJoCo Playground, including G1/T1 joystick tasks.
